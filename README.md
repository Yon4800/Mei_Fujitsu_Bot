# Mei-san LLM Bot (Fujitsu x86 Mini PC)

このディレクトリは、富士通のミニPC（Intel Core i3-6100T x86_64）サーバーで動作する、Gemini API搭載のMisskey用LLMボット「メイさん」のソースコードです。

## 概要

メイさんは、他のシングルボードコンピュータ（SBC）のボットたちを見守り、なだめる「みんなの中心的存在」であり、「普通・常識的・穏やか」な性格のお姉さんキャラクターです。

x86_64アーキテクチャの安定したサーバーパワー（8GBメモリやアクティブ冷却）を持ち、他のSBCボットのように熱暴走したりメモリ不足でフリーズしたりすることなく、安定して動作します。

### 特徴
1. **会話機能 (`+LLM`)**: メイさんと通常の会話を行うことができます。
2. **対話相手の記憶 (`+LLM` 会話時の自動学習 & `+M` コマンド)**: 会話の中であなたの特徴（名前の好み、趣味、仕事、性格、出来事など）を記憶します。会話ごとに記憶は上書き・統合され、以降の会話は記憶に基づいて自然に行われます。
3. **好感度システム**: 会話の文脈や態度によって好感度が 0〜100 の間で変動し、それに応じてメイさんの態度もデレデレになったり、少しよそよそしくなったりと変化します。
4. **システムステータス表示 (`+STATS`)**: ホストマシン（富士通のミニPC）のCPU使用率、メモリ使用率、ロードアベレージ、およびCPU温度を正確に取得し、メイさんの語り口で報告します。
5. **仮想経済圏の連携**: 他のボットたちと共通の `shared_economy.json` と連携し、為替レートの取得や資産残高の確認が行えます。

## コマンド一覧

Misskeyでボットのアカウントに向けて、以下のタグを含めてノートまたはリプライを送ることで動作します。

| コマンド | 説明 |
| :--- | :--- |
| `+LLM <メッセージ>` | メイさんと通常会話を行います。会話内容に応じて好感度や「あなたの記憶」が自動で更新されます。 |
| `+M` | 現在のあなたへの好感度（態度で表現）と、**あなたに関して記憶している内容**を教えてくれます。 |
| `+STATS` | ミニPCサーバーの現在のCPU使用率、メモリ使用率、ロードアベレージ、CPU温度を取得し、報告します。 |
| `+TALK` | グループ会話（リレー会話）に参加している場合に、順序に従って応答します。 |

## ディレクトリ構成

- `main.py`: ボットの本体プログラム。MisskeyとのWebSocket接続、メッセージ処理、Gemini APIの呼び出し、レスポンスタグ（好感度、記憶）の解析などを行います。
- `state_manager.py`: ユーザーの好感度、記憶（プロファイル要約）、会話回数、最終アクセス時間などを `state.json` に保存・管理します。
- `shared_economy_helper.py`: 他のボットと共通の仮想経済データ（`shared_economy.json`）を処理するための共通モジュールです。
- `requirements.txt`: 必要なPythonパッケージの一覧です。
- `env.example`: 環境変数の設定サンプルです。

## セットアップ手順

1. **必要なパッケージのインストール**
   ```bash
   pip install -r requirements.txt
   ```

2. **環境変数の設定**
   `env.example` をコピーして `.env` を作成し、中身を編集します。
   ```bash
   cp env.example .env
   ```
   以下を設定してください：
   - `SERVER`: 接続先Misskeyサーバーのドメイン（例: `misskey.io` など）
   - `TOKEN`: ボットアカウントのアクセストークン（「ノートの作成・削除」「ローカルタイムラインの閲覧」「通知の閲覧」「フォロー・アンフォロー」などの権限が必要）
   - `APIKEY`: Google Gemini API Key

3. **起動**
   ```bash
   python main.py
   ```
